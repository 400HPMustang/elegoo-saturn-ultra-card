# Elegoo Saturn Ultra Card

A Home Assistant Lovelace YAML card for Elegoo resin printers using the `elegoo_printer` integration.

This is not a compiled JavaScript dashboard plugin. HACS can track the template file, but you still need to paste or include the Lovelace YAML in your dashboard.

After install/update, copy the card YAML from `lovelace/elegoo_saturn_ultra_card.yaml` or from the root `elegoo_saturn_ultra_card.jinja` file into your Lovelace dashboard.
